## 一、前言

### 使用说明

- 本软件主要功能以WCS客户端为主，类似前端，需要配合WCS服务端进行使用。
- 除了WCS相关功能，本软件还提供了一些额外附加功能，并不依赖WCS服务，可随时使用。
- 使用本软件前，请确保现场WCS服务端版本在4.0以上。
- 推荐在个人电脑或现场工控机上使用，不建议在服务器上运行。
- 本客户端无法完全替代前端，主要用于调试阶段。
- 程序目前处于测试阶段，bug较多且更新频繁，请及时更新至最新版本。
- 如遇功能无法使用，请先尝试将WCS服务端更新至最新版本。
- 请注意屏幕分辨率设置——分辨率过低或缩放倍数过大会导致界面显示不全。

### Ⅳ、我该如何给现场的服务器或者工控机部署（或更新）？

首先因为服务器没有外网的原因，会给后续升级带来很大的困扰！所以，这里我们强烈建议使用自己电脑上运行的最新版进行打包，然后部署到现场的服务器或工控机。切勿使用MinIO和云平台上的包——版本太低，且服务器无外网，会导致无法更新。

下面介绍如何正确地给现场服务器部署：

1. 首先在自己电脑上运行此软件，确保电脑接入外网
2. 将当前程序自动升级至最新版本
3. 在软件的"关于"页面使用打包功能

打包功能分为两种：**部署包**和**更新包**。

- **部署包**：用于在新电脑上进行全新部署
- **更新包**：用于给现有电脑上的程序进行升级

![打包功能](/images/image-6.png)

如上图所示位置，这里首次给现场部署我们选择【部署包】，等待程序自动打包完成，将打包完成的压缩包放置新的电脑上，按照部署教程栏目的方式进行常规部署即可。

**更新：**

由于现场服务器没有外网，后续需要对服务器上的程序进行升级时，就需要使用打包功能中的【更新包】功能。如上图所示，点击"更新包"按钮，等待更新包打包完成。然后将得到的压缩包中的文件全部覆盖到现场服务器上该软件所在的目录下即可。

::: danger 重要提示
- 本更新方法适用所有无法通过外网自动升级的设备，切勿自行打包更新，可能会造成一些基础数据丢失
- 【部署包】是全新的包，会覆盖原有的配置和数据
- 【更新包】则不会覆盖配置和数据，所以要根据场景慎重选择！！！
:::

## 三、软件基础功能介绍

### Ⅰ、首次启动

软件首次部署完，运行程序，我们会看到如下界面：

![首次启动预览图](/images/image-7.png)

<p style="text-align: center;color: #888;">首次启动预览图</p>

- **仓库名称**：根据当前部署的现场来命名，比如"成品库"、"小件库"和"恒鑫5号库"等等，总之就是让人能够一眼看懂的

![主界面布局预览图](/images/image-8.png)

### Ⅲ、软件设置介绍

![设置界面预览图](/images/image-9.png)

<p style="text-align: center;color: #888;">设置界面预览图</p>

::: warning 注意
本软件配置项基本都涵盖在设置界面，提供了可视化的用户界面，方便用户修改配置，请勿直接编辑 appsettings 文件，以防改错，带来不必要的麻烦！！！

更改完任何配置都需要点击右上角的保存按钮，否则更改不生效！
:::

#### 1. 主题设置

- **软件主题**：分为"亮色"和"暗色"两种主题，根据个人喜好选择即可

#### 2. 颜色设置

- **软件颜色**：分为"蓝色"、"红色"、"绿色"和"橙色"四种颜色，根据个人喜好选择即可

#### 3. 背景设置

- **软件背景**：分为 Gradient（渐变）、Flat（纯色）和 Bubble（气泡）三种背景，根据个人喜好选择即可

#### 4. 语言设置

- **软件语言**：分为"中文"和"英文"两种语言，根据个人喜好选择即可

#### 5. MQTT 配置

- 根据现场需求，如果有需要使用MQTT数据推送功能，需要先勾选"启用MQTT数据推送"选项，然后配置MQTT服务器地址
- 该功能目前仅用于S7数据采集功能，前端订阅该主题后，即可实时获取S7设备采集到的数据显示到大屏上

#### 6. 仓库配置

- **仓库名称和IP地址**：此处可用来编辑当前软件显示的仓库名称，根据实际情况填写
- **支持多仓库**：如果当前现场有多个仓库，需要分别配置；右键仓库卡片可弹出菜单，可选择"新增"或"删除"
- 如果换了现场，需要重新在此处编辑仓库名称和IP地址

#### 7. 更新设置

- **同意获取最新测试版**：勾选该选项后，代表用户同意获取最新的测试版软件，包括alpha版和beta版，并能接受相关bug风险
- **更新源**：我们提供了两个源"Github"和"Gitee"，用户可以根据自己的网络环境选择不同的源进行更新；默认建议使用Gitee源，因为Github源在国内访问速度较慢

## 四、WCS客户端功能介绍

::: info 核心功能
WCS客户端部分，是本软件的核心功能，接下来会以大量的篇幅来介绍！
:::

### Ⅰ、WCS 首页

WCS 首页主要显示的内容为对应的仓库信息，这里显示仓库列表来自设置中的仓库配置，接下来针对仓库卡片进行详细介绍：

- 首先仓库卡片顶部左侧显示的为仓库名称标题，下面有对应的仓库ip地址；名称旁边有一个状态图标，用来表示当前仓库的在线或离线状态
  - 如果图标为**绿色**，表示当前仓库在线
  - 如果图标为**红色**，表示当前仓库离线
  - 离线状态下，仓库下的所有功能都将被禁用，无法使用；您需要先检查wcs服务器是否正常运行，或者IP地址是否配置正确

- 仓库卡片顶部右侧一排按钮，分别为：
  - **在线地图监控**：点击后，会打开当前仓库对应的在线地图监控页面，展示当前仓库的实时监控数据
  - **设备中心**：点击后，会打开当前仓库对应的设备中心页面，展示当前仓库的设备数据
  - **任务中心**：点击后，会打开当前仓库对应的任务中心页面，展示当前仓库的任务数据
  - **基础数据导入**：点击后，会打开当前仓库对应的基础数据导入页面，用户可以导入本地的地图、Mode和故障表等基础数据
  - **历史回放**：点击后，会打开当前仓库对应的历史回放页面，用户可以查看当前仓库的历史运行回溯画面
  - **工具中心**：点击后，会打开当前仓库对应的工具中心页面，展示当前仓库的工具列表

本软件提供了本地设备 Json 可视化功能，用户可以将本地设备 Json 文件可视化展示在软件中，方便用户查看和分析设备数据。

### Ⅲ、本地任务 Json 可视化

本软件提供了本地任务 Json 可视化功能，用户可以将本地任务 Json 文件可视化展示在软件中，方便用户查看和分析任务数据。
