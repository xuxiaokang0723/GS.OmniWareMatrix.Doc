# 前言

::: info 版本信息
当前文档基于 V1.0.0-Beta.1 版本制作
:::


## 使用说明

- 本软件主要功能以WCS客户端为主，类似前端，需要配合WCS服务端进行使用。
- 除了WCS相关功能，本软件还提供了一些额外附加功能，并不依赖WCS服务，可随时使用。
- 使用本软件前，请确保现场WCS服务端版本在4.0以上。
- 推荐在个人电脑或现场工控机上使用，不建议在服务器上运行。
- 本客户端无法完全替代前端，主要用于调试阶段和问题排查分析。
- 程序目前处于测试阶段，bug较多且更新频繁，请及时更新至最新版本。
- 如遇功能无法使用，请先尝试将WCS服务端更新至最新版本。
- 请注意屏幕分辨率设置——分辨率过低或缩放倍数过大会导致界面显示不全。
