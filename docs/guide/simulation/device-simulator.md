# 设备模拟器使用教程

## 第一步：准备工作
1. 部署井松全家桶（包括前端、PDA、WMS、WCS、WES、工艺DB发布、地图json导入等）
2. 配置WMS基础数据，主要就是仓库、库区、货架、月台、巷道可达性等
3. 根据各自现场的业务需求，提前画好地图导入wcs和工艺发布

### 注意事项：
1. WCS版本必须是20260325之后的版本；
2. 地图编辑器版本也必须是20260325之后的版本；
3. 地图导出一定要使用单独的“发布调试工具地图”按钮；
4. 接下来本地模拟所使用的地图json文件，都需要用上面导出的json文件；

![地图导出](/images/simulation/image-2.png)


## 第二步：启动模拟器
1. 准备工作做完后，将井松全家桶软件全部启动起来；
2. 调试工具首次部署时，要选择管理员模式，否则看不到设备模拟器菜单；
2. 启动调试工具软件；
3. 打开设备模拟器菜单；
4. 点击导入地图json文件按钮，弹出的wcs地址，本地保持默认127.0.0.1即可；
5. 点击启动模拟器按钮；

![启动模拟器](/images/simulation/image-4.png)


## 第三步：开始使用并测试流程
1. 模拟器启动之后，等待wcs前端设备页面所有设备的链接状态都变成已连接之后；
2. 点开对应设备，查看设备详情；确保设备状态啥的是否正常；如果不正常，需要检查WCS相关配置是否正确；
3. 正常的话，就开始按业务需求进行测试吧；

::: tip 测试顺序小提示
- 模拟测试一般是先下手工任务测试，手工任务主要测试的是地图和算法配置以及wcs相关配置是否存在问题；
- 手工任务测试完成后，再测试工艺流程，通过触发工艺来产生对应的任务；
:::


## 常见问题解答

### 1. 输送线货位残留占位问题？

我们在使用的过程中，肯定会遇到输线货位占位问题；当我们给输送线下达任务的时候，当任务结束后，就会在任务的终点留下一个占位；这个占位会导致后续的任务无法通过这个位置，从而导致任务无法执行；如下图所示：

![输线货位占位](/images/simulation/image-5.png)

上图中，1085处就是残留了一个占位，导致新的任务一直在1086处处于等待状态；这时候除非我们重启模拟器来重置整个现场，否则无法解决这个问题；但是每次都重启模拟器未免太麻烦了；所以还有其他的方法来解决这个问题，如下图所示：

![解决输线货位占位问题](/images/simulation/image-6.png)

上图中，我们可以通过wcs前端的对应输送线设备的详情页面中，点击货位状态栏，选中对应的货位号1085，右键弹出“清除占位”选项，点击后即可清除模拟器中该货位的占位状态；后续的任务即可正常执行了；


### 2. 我该如何触发工艺？
- 首先取决于我们所配置的工艺，如果你得工艺是通过PDA或者其他接口来触发，那么直接打开PDA或者相关接口调试工具（swagger等）来触发即可！比如空托上架工艺，直接在pda前端页面使用该功能触发即可；
![空托上架工艺演示](/images/simulation/image-7.png)

- 如果我们工艺配置的是需要通过业务占位来触发，也就是通过PLC触发！这时我们可以来到模拟器界面，选择工艺触发源所配置的输送线设备，点击触发源选项卡，如下图：
![模拟器触发业务占位](/images/simulation/image-8.png)
上图中，我们看到的既是当前输送线所绑定的工艺触发源，我们根据自身需要选择对应的工艺，右键即可弹出触发工艺按钮；点击即可弹出触发次数和一些预填参数配置，根据自身需求进行设置；如下图：
![模拟器触发业务占位](/images/simulation/image-9.png)
