## 我该如何给现场的服务器部署（或更新）？

首先因为服务器没有外网的原因，会给后续升级带来很大的困扰！所以，这里我们强烈建议使用自己电脑上运行的最新版进行打包，然后部署到现场的服务器或工控机。切勿使用MinIO和云平台上的包——版本太低，且服务器无外网，会导致无法更新。

下面介绍如何正确地给现场服务器部署：

**第一步：首先在自己电脑上运行此软件，确保电脑接入外网**

**第二步：将当前程序自动升级至最新版本**

**第三步：在软件的"关于"页面使用打包功能**


打包功能分为两种：**部署包**和**更新包**。

- **部署包**：用于在新电脑上进行全新部署
- **更新包**：用于给现有电脑上的程序进行升级

![打包功能](/images/image-6.png)

如上图所示位置，这里首次给现场部署我们选择【部署包】，等待程序自动打包完成，将打包完成的压缩包放置新的电脑上，按照部署教程栏目的方式进行常规部署即可。

**更新：**

由于现场服务器没有外网，后续需要对服务器上的程序进行升级时，就需要使用打包功能中的【更新包】功能。如上图所示，点击"更新包"按钮，等待更新包打包完成。然后将得到的压缩包中的文件全部覆盖到现场服务器上该软件所在的目录下即可。

::: danger 重要提示
- 本更新方法适用所有无法通过外网自动升级的设备，切勿自行打包更新，可能会造成一些基础数据丢失
- 【部署包】是全新的包，会覆盖原有的配置和数据
- 【更新包】则不会覆盖配置和数据，所以要根据场景慎重选择！！！
:::
