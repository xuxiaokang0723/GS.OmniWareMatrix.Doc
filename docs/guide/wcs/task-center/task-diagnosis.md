# 任务诊断 （内测中）

::: tip 功能特色
- 以往当主任务出现异常时，用户需要手动查看任务和设备的状态，在好几个页面来回切换，才能定位问题。而现在的任务诊断功能，将任务和设备的状态集成在一个界面展示，用户可以实时查看任务和设备的状态，以及根据状态分析出问题所在。
- 同时调试工具，自身还提供了实时任务诊断功能，根据任务和设备的实时状态，给出分析和建议，帮助小白用户快速定位和解决任务执行中的问题。
- 核心是将任务和设备的状态集成在一个界面展示，接下来遇到任务上的问题，先用诊断功能打开排查，或者将诊断页面截图给开发协助分析。
:::

::: warning 注意事项
- 任务诊断功能目前处于测试阶段，仅支持输送线和堆垛机两种设备诊断，后续会逐渐增加其他设备类型的诊断功能。
- 诊断出来的结果仅供参考，可能存在判断错误的情况，用户需要结合实际情况进行判断和处理。
- 诊断功能无法分析程序上的bug和工艺流程设计上的问题，比较鸡肋，看看就好，如果对你有帮助，也可以给我点个赞。
:::

## 使用方式
任务诊断功能可以通过两种方式打开，方法1需要额外确保打开了“设备中心”界面。

### 方法1
- 在任务中心界面，右键选择需要诊断的任务，选择任务诊断选项，即可打开任务诊断界面。如下图：
![任务诊断界面](/images/wcs/task-center/2.png)

- 在任务中心界面打开的任务诊断界面，需要配合设备实时状态功能使用，所以在使用前，首先确保打开了“设备中心”界面。如下图：
![设备中心界面](/images/wcs/task-center/3.png)

### 方法2
- 在线地图监控页面，顶部任务栏展开，右键选择需要诊断的任务，选择任务诊断选项，即可打开任务诊断界面。如下图：
![任务诊断界面](/images/wcs/task-center/4.png)


## 功能介绍
界面整体设计为左右布局，左侧展示任务信息和设备的实时状态，右侧展示的为调试工具软件根据当前状态分析的诊断结果。

### 1.主任务信息
任务信息包括主任务和子任务的相关信息，主任务仅展示了一些重要的信息；

### 2.子任务信息
子任务信息为主任务的任务拆分明细，可以看到主任务是怎么拆分的，以及子任务的完成情况等。

### 3.设备状态
子任务下面对应展示了正在执行该子任务的设备实时状态，包括设备的运行状态、任务执行进度、设备位置等。

### 4.诊断结果
根据任务和设备的实时状态，调试工具会根据一定的规则和算法，分析出任务执行中的问题，并给出诊断结果。不要盲目相信软件诊断的结果，自己根据实际情况，也可以根据设备的运行状态和任务的执行进度，判断出问题所在。
