# 在线地图监控页面

本软件提供了在线地图监控功能，用户可以实时查看当前仓库的地图运行状态，包括设备位置、任务状态、故障信息等。

::: warning 注意
当项目地图比较大的情况下，地图操作会变的异常卡顿，地图越大，影响越严重，如果已经严重影响到你的使用，可放弃使用该功能！给您带来不变，我们深表歉意，目前这个情况属于框架和设计上原因，短时间内无法修复！！！
:::

## 监控界面元素介绍

首先整个地图画布区域，显示了整个仓库的布局，用户可以在整个区域内看到立库布局、设备动态、输送线状态、任务数据等。

### 悬浮窗介绍

在地图展示区域内，内置了各种悬浮窗，用户可以点击悬浮窗表头，可展开或收起悬浮窗。

- 左侧设备悬浮窗：展示了当前立库的所有设备数据，包括设备ID、设备类型、设备状态等，同时右键点击设备项，可弹出菜单项，包括“复位”、“锁定”、“解锁”、“状态详情”等；
- 顶部任务悬浮窗：展示当前立库的主任务数据，包括任务ID、任务类型、任务状态等，同时右键点击任务项，可弹出菜单项，包括“暂停”、“取消”、“任务详情”等；
- 右上角小地图悬浮窗：展示了当前立库的小地图布局，用户可以在该区域内查看整体的布局；
- 右侧楼层悬浮窗：展示了当前立库的所有楼层数据，选中或取消选中楼层，即可在地图展示区域内显示或隐藏该楼层的货位；
- 右侧图例悬浮窗：展示了当前立库的所有货位类型和状态，用户可以根据图例来判断货位的状态；
- 底部功能按钮：主要用来控制当前地图布局，包括“放大”、“缩小”、“重置”、“定位”等；
- 右下角地图信息栏：展示了当前立库的地图的尺寸和当前地图的缩放比例以及Fps；

### 地图元素介绍

- 移动设备图标：移动设备图标在地图画布上，属于地图上的装饰器，由圆角矩形内部设备名称加固定图标组成，大小不会随地图画布的缩放而变化，但是位置会根据设备的位置而变化；不同的移动设备静止时的颜色是不相同的，具体可以看图例介绍；同时用户可以根据几个特殊颜色来判断当前设备的状态，比如：绿色表示设备正常运行，黄色表示设备手动，红色表示设备故障；单击对应的设备图标，可弹出该设备的详情页面；

- 输送线货位图标：输送线货位图标在地图画布上，属于一个地图节点，由圆形内部货位号组成，有些货位具有特殊含义的也会有对应的标记，比如外检货位会有“WJ”标记；大小会随地图画布的缩放而变化；不同的货位类型会有不同的颜色表示，具体可以看图例介绍；同时用户可以根据几个特殊颜色来判断当前货位的状态，比如：黄色表示货位有占位，红色表示货位故障；双击输送线货位，会弹出当前货位的状态信息，主要是PLC反馈的状态；右键对应的货位，可查看当前货位在地图中的配置信息；

- 路径图标：路径图标在地图画布上，属于一个地图线段，由多个路径点组成，路径点之间用直线连接起来；目前路径主要就是一个展示路径用的，可右键对应的路径线段，可查看该段路径在地图中的配置信息；

- 货物图标：货物图标和移动设备类似，属于地图上的装饰器，主要显示在输送线上，由单独的固定箱子图标组成，大小不会随地图画布的缩放而变化，会根据当前货位反馈的占位状态变化；单击对应的货物图标，可弹出该货物对应的任务信息；

## 重要功能介绍

### 设备操作
- 用户可以在左侧设备悬浮窗内，对设备进行操作，包括复位、锁定、解锁、状态详情等；
- 也可以点击地图监控区域内的对应的移动设备图标，可弹出设备详情页面，在设备详情页面内，可以有更多的操作；（具体操作请参考[设备详情页面]）

### 任务操作
- 用户可以在顶部任务悬浮窗内任务列表中，对任务进行操作，包括暂停、取消、任务详情等；
- 也可以点击地图监控区域内的货物图标或移动设备图标，显示对应的任务号信息，可通过点击任务号快速导航到任务详情页面；（具体操作请参考[任务详情页面]）

### 地图操作
- 通过滚动鼠标中键可以缩放地图，也可以通过底部的“+”、“-”按钮来实现地图的缩放；
- 通过鼠标右键按下并拖动地图，可实现地图的平移；
- 通过快捷键“Ctrl + F”或者底部的”查找“按钮，可以快速打开查找菜单，输入要查找的货位号或设备ID，即可快速定位到对应的货位或设备；
- 通过快捷键“Ctrl + A”或者底部的“自适应”按钮，可以重置地图到原始大小和位置；
- 通过快捷键“Ctrl + H”或者底部的“隐藏/显示”按钮，可以隐藏或显示地图上的货物和移动设备；按一下隐藏货物，再按一下隐藏设备，再按一下全部显示；


### 设备悬浮窗介绍
- 点击左侧设备悬浮窗顶部的“设备列表”，即可展开或收起设备列表；
- 在收起和展开状态下，我们都能看到设备统计信息，由圆形图标和数字组成；
    - 无背景颜色代表设备总数；
    - 绿色背景颜色代表运行的设备数量；
    - 黄色背景颜色代表警告的设备数量；
    - 红色背景颜色代表故障设备的数量；
    - 灰色背景颜色代表未链接的设备数量；
- 用户可以在设备悬浮窗内，右键对应的设备项，可弹出菜单项，包括“复位”、“锁定”、“解锁”、“状态详情”等；
- 展开设备列表后，在顶部的设备类型筛选框，用户可以根据设备类型来筛选设备，比如：输送线、堆垛机和RGV等；
- 设备类型筛选框右侧下拉按钮，点击即可展开对当前设备类型的批量操作，现支持：批量复位、批量锁定、批量解锁等；
- 展开设备列表后，在顶部的搜索框内，输入要查找的设备ID，支持模糊查询，即可快速定位到对应的设备；


### 任务悬浮窗介绍
- 点击顶部任务悬浮窗顶部的“任务列表”，即可展开或收起任务列表；
- 在收起和展开状态下，我们都能看到任务统计信息，由圆形图标和数字组成；
    - 无背景颜色代表任务总数；
    - 绿色背景颜色代表运行中的任务数量；
    - 黄色背景颜色代表暂停的任务数量；
    - 红色背景颜色代表报警的任务数量；
    - 灰色背景颜色代表新任务的任务数量；
- 用户可以在任务悬浮窗内，右键对应的任务项，可弹出菜单项，包括“暂停”、“取消”、“任务详情”等；
- 展开任务列表后，在顶部的搜索框，可选择筛选类型来查找任务，比如选择任务号，输入任务号即可快速定位到对应的任务；
- 顶部左侧的“+”按钮，点击即可添加手工任务，输入对应的起点和终点即可；
