# WCS 首页

WCS 首页主要显示的内容为对应的仓库信息，这里显示仓库列表来自设置中的仓库配置，接下来针对仓库卡片进行详细介绍：

![WCS 首页](/images/wcs/wcs-home.png)
<p style="text-align: center;color: #888;">WCS 首页</p>

- 首先仓库卡片顶部左侧显示的为仓库名称标题，下面有对应的仓库ip地址；名称旁边有一个状态图标，用来表示当前仓库的在线或离线状态；如果图标为绿色，表示当前仓库在线；如果图标为红色，表示当前仓库离线；离线状态下，仓库下的所有的功能都将被禁用，无法使用；您需要先检查wcs服务器是否正常运行，或者IP地址是否配置正确；

- 仓库卡片顶部右侧一排按钮，分别为：
  - 在线地图监控：点击后，会打开当前仓库对应的在线地图监控页面，展示当前仓库的实时监控数据；
  - 设备中心：点击后，会打开当前仓库对应的设备中心页面，展示当前仓库的设备数据；
  - 任务中心：点击后，会打开当前仓库对应的任务中心页面，展示当前仓库的任务数据；
  - 基础数据导入：点击后，会打开当前仓库对应的基础数据导入页面，用户可以导入本地的地图、Mode和故障表等基础数据；
  - 历史回放：点击后，会打开当前仓库对应的历史回放页面，用户可以查看当前仓库的历史运行回溯画面；
  - 工具中心：点击后，会打开当前仓库对应的工具中心页面，展示当前仓库的工具列表；

- 仓库卡片的主体内容主要分为三个报表展示区域：
  - WCS 服务器资源监控：展示当前仓库的wcs服务器资源使用情况，包括CPU占用率、内存占用率、磁盘占用率等；
  - 任务池：展示当前仓库的任务状态，包括待处理任务数量、正在处理任务数量、历史已完成任务数量等；
  - 设备监控：展示当前仓库的设备状态，包括运行设备数量、故障设备数量、离线设备数量等，以及故障统计；

- 最后，仓库卡片的右侧部分展示的主要是一些版本信息，包括运行时间、WCS 版本、算法版本、地图版本、工艺版本；
