# 调试工具 V1.0 版本更新说明

::: tip 写在前面：

从 2025 年 4 月 23 日首个预览版悄然上线，到如今近一年的时光悄然沉淀。这期间，不仅是代码的迭代与打磨，反复推敲的重构优化，以及对每一个操作细节的较真与完善。历经数次推翻重来的重构、数不清的细节调整，终于迎来了第一个里程碑式的 1.0 系列版本 。此次更新堪称一次全面革新，操作逻辑与界面布局较之前版本有大幅调整，只为给你带来更贴合业务、更高效流畅的使用体验。

当然对于此版本你也可以保持观望，毕竟还是一个Beta版本，bug 众多，界面操作方式的变革，您可以等待组织完培训后正式版发布之后再进行正式使用。如果你选择了体验新的版本，帮忙测试 bug，请务必将现场wcs服务端也更新至最新版本。

以下简要列举本次版本的核心特色功能，也请你在使用过程中多一份耐心探索：

:::

### 三大重磅核心功能

1. **多仓库并行管理** ：彻底告别旧版仅支持单仓库操作的局限，针对现场多仓库（常见双仓库）的实际场景，无需反复切换URL配置、重启软件，可直接在系统内一键切换管理多个仓库，大幅降低操作成本，提升跨仓库业务处理效率。
2. **实时监控全景可视化**：新增全场地图式监控界面，集中可视化展示设备运行状态、货位占用情况、货物流转轨迹及任务执行进度，实现业务全流程实时掌控，无需分散查询即可全局了然。
3. **历史轨迹回溯功能**：新增历史回放界面，支持业务操作、任务执行轨迹的完整回溯，为业务复盘、问题排查提供精准数据支撑，助力快速定位核心节点。

### **其他新增功能**

1. 新增浏览器模式标签页，多页面切换丝滑便捷，优化业务操作连贯性；
2. 首页界面全新重构，布局与交互逻辑优化，视觉体验与操作便捷性双重提升；
3. 原先设备中心页面重构，采用简单的列表式样布局与操作；
4. 数据采集增加MQTT推送功能，可将采集到的数据推送给大屏或者其他系统；
5. 新增打包功能，方便无网络环境下的部署和更新；
6. 新增多项本地测试工具，方便排查网络、地图、redis等问题；
7. ……

### **其他核心优化**

1. 导航系统全面重构，支持多种页面类型灵活跳转，逻辑更清晰、操作更高效；
2. 程序初始化流程和依赖注入重构，增加子菜单和标签菜单两种类型页面；
3. 配置系统升级适配IOptions模式，实现配置管理标准化，降低维护成本；
4. 访问后端API重构，提供统一的接口访问服务；
5. 新增多开验证机制，严格限制单实例运行，保障数据交互安全与系统稳定性。
6. ……

### **版本更新注意事项**

1. 本次版本界面布局、操作路径与旧版差异较大，建议首次使用时预留少量时间熟悉新功能逻辑，快速适配新体验。
2. 如果想要在地图监控中获得最佳体验，地图也需要符合最新的wcs地图规范，否则可能会导致地图监控功能异常。
3. 若使用过程中遇到操作疑问或功能异常，欢迎随时反馈，你的每一条建议都是我们完善产品的重要动力。
4. 作为1.0系列的首个beta版本，我们仍在持续打磨优化，后续将根据大家的使用反馈，快速迭代升级，不断提升产品稳定性与实用性。
5. 本次更新跨度较大，建议软件内部人员优先更新测试，其他使用人员，暂可忽略更新，等正式版发布再做更新！

### **在线监控地图注意事项**

1. 堆垛机的轨道点需要开启对应的设备、类型设置成轨道点以及配置对应的列；
2. 注意楼层字段也要配置一下，对应地图里面Floor字段；
3. RGV设备类型要选择标准RGV；
4. 货架点的类型需要设置成货架点；

::: warning 注意
当项目地图比较大的情况下，地图监控操作会变的异常卡顿，地图越大，影响越严重，如果已经严重影响到你的使用，可放弃使用该功能！给您带来不变，我们深表歉意，目前这个情况属于框架和设计上原因，短时间内无法修复！！！
:::
