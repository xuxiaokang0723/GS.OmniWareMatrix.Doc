# 通知公告

## 2026年3月2日，V1.0.0-Beta.4 版本重磅功能通知。

::: tip 
新增任务诊断功能，告别以往繁琐的操作，集成任务状态和设备状态在一个界面，用户可以实时查看任务和设备的状态，以及根据状态分析出问题所在。详情请参考[任务诊断功能](guide/wcs/task-center/task-diagnosis.md)。
:::



## 2026年1月27日，V1.0.0-Beta.2 版本发布更新通知。

::: tip 
如果您当前使用的版本已经大于1.0.0-Beta.2，请忽略此通知！否则请往下看！！！。
:::

::: warning 注意
由于 1.0 beta2 版本新增了语义化版本号和解析功能，导致自动更新功能受到影响：

- 如果您当前使用的版本低于1.0.0-Beta.2，请手动升级到1.0.0-Beta.2版本（前往MinIO下载升级包）。
- 如果不进行手动升级一次，软件将永久无法自动更新最新版本。
- 如果您已经手动升级到1.0.0-Beta.2版本，请忽略此通知。
:::
