# 关于

## 关于WCS调试工具

WCS调试工具是一款专业的仓库控制系统调试工具，主要用于WCS系统的调试和维护工作。

### 版本信息

- **当前版本**: V1.0.0-Beta.1
- **更新频率**: 持续更新中
- **支持平台**: Windows 10及以上

### 主要特性

- ✨ 支持WCS客户端功能，提供类似前端的操作体验
- 🔧 提供本地工具功能，不依赖WCS服务
- 🎨 支持自定义主题、颜色和背景
- 🌐 支持多仓库配置和管理
- 📦 支持自动更新和离线部署
- 🔍 提供可视化的地图、设备和任务数据展示

### 技术支持

如遇到问题或需要技术支持，请联系技术支持团队。

### 系统要求

- **操作系统**: Windows 10 或更高版本
- **WCS服务端**: 4.0 或更高版本
- **.NET运行时**: 自动包含
- **网络**: 建议有外网连接（用于自动更新）

### 更新说明

软件会定期发布更新，包括：

- 🐛 Bug修复
- ✨ 新功能添加
- 🎨 界面优化
- 📈 性能改进

建议保持软件为最新版本以获得最佳使用体验。
