## 快速开始

### 安装

从以下任一位置下载调试工具：

1. **MinIO下载地址** - 内部存储服务器
2. **企业云平台下载地址** - 企业云端平台

::: tip 提示
下载的包可能不是最新版本，但在有外网的情况下可自动升级至最新版！
:::

### 部署

1. 解压下载的压缩包到本地任意位置（推荐D盘）
2. 找到 `GS.OmniWareMatrix.Desktop.exe` 文件
3. 右键选择"发送到" → "桌面快捷方式"
4. 双击桌面快捷方式即可运行

### 使用说明

- 本软件主要功能以WCS客户端为主，需要配合WCS服务端使用
- 使用前请确保现场WCS服务端版本在4.0以上
- 推荐在个人电脑或现场工控机上使用
- 程序处于测试阶段，请及时更新至最新版本

::: warning 注意
请注意屏幕分辨率设置——分辨率过低或缩放倍数过大会导致界面显示不全
:::

## 主要功能

- **WCS首页** - 查看仓库信息和在线状态
- **在线地图监控** - 实时监控仓库运行状态
- **设备中心** - 管理和监控设备状态
- **任务中心** - 查看和管理任务执行情况
- **基础数据导入** - 导入地图、Mode和故障表等数据
- **历史回放** - 回溯查看历史运行画面
- **工具中心** - 各种实用工具集合

## 支持与反馈

- 如遇功能无法使用，请先尝试将WCS服务端更新至最新版本。
- 如遇软件bug，请及时反馈至开发者，我们会尽快修复。
